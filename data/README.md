# Data access

Raw data are **not** included in this repository.

- **Advan mobility data (2023)**: licensed; available to academic researchers through Dewey. Place raw files in `data/raw/advan/`.
- **ACS 5-year estimates**: public; retrieved via the Census API (see `src/00_download_public.py`).
- **NYC park polygons**: NYC Open Data (Parks Properties).
- **ParkServe**: Trust for Public Land.

Derived, aggregated outputs (block-group LPUR, model inputs without raw visit counts) can be shared on request.
